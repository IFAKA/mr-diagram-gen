## Guidelines

Diagrams ARE valuable for:
- New features with multiple components interacting
- API changes (request/response flows)
- Database/schema changes
- Refactoring or restructuring
- New modules/packages
- Complex algorithm changes

Diagrams are NOT needed for:
- Simple bug fixes (typos, minor logic fixes)
- Configuration-only changes
- Documentation updates
- Test file additions only
- Dependency version bumps
- Single-file changes with clear purpose

    "reason": "Brief explanation",
    "confidence": 0.0-1.0
}

Only include diagram types that would genuinely help reviewers. Less is more.
